Privacy policy — Paperclip Email Sync

Last updated: 31 October 2026

Who uses it

Paperclip Email Sync is a private tool run by Frank Keating for his own use. Only Gmail accounts that belong to Frank are connected to it.

What it accesses

With the account owner's permission, granted through Google's own sign-in page, the tool reads, searches, labels and drafts email in the connected Gmail account. It sends or deletes email only after the owner approves each message.

How data is kept

Access tokens and any email data are stored only on the owner's private server. Email content is used only to help the owner manage his own mail. It is never sold, shared with third parties or used for advertising.

Google user data

This tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Once removed, the tool can no longer reach that account.
